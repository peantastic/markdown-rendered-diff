# Markdown Rendered Diff

[English](README.md) · [Tiếng Việt](README.vi.md) · 日本語 · [简体中文](README.zh-cn.md)

Markdown の変更を、ソースの差分ではなく**レンダリング後の見た目**でレビューできます。

- 段落・リスト・見出しを単語単位で差分表示。日本語・中国語・ベトナム語にも対応 (`Intl.Segmenter` で分かち書き)。
- 表: 追加 / 削除された行と、変更されたセルだけをハイライト (`colspan`/`rowspan` を含む HTML の表にも対応)。
- Mermaid 図は変更前 / 変更後を並べて描画し、図のソース差分も確認できます。
- 統合 / 左右並べて表示 (`s`)、変更なしブロックの折りたたみ (`c`)、変更ごとの確認済み (`x`) とファイル単位の確認済み (`v`)。
- サイドバー: **変更ファイル** (ツリー / 一覧、M/A/D バッジ)、**変更のある見出し**、**ファイル履歴**。
- 比較基準: HEAD、前回のレビュー以降、PR/MR と同じ、未ステージ、任意のコミット/ブランチ、直近の Claude Code ターン (任意)。
- ブロックに約 1 秒カーソルを置くと blame を表示。

**使い方:** git リポジトリを含むフォルダーを開き、アクティビティ バーの **Markdown Diff** を開くか、`.md` ファイルを開いて **レンダリング差分を開く** ボタン / `Alt+Shift+D`。Review タブで `?` を押すとショートカット一覧を表示します。

**Claude Code のターン追跡 (任意、既定はオフ):** コマンド「Claude Code のターン追跡を有効化…」を実行して確認すると、`~/.claude/settings.json` に 2 つのフックを追加します (事前にバックアップ)。Claude が `.md` を編集する直前の内容を保存します。「無効化」コマンドで削除できます。

**プライバシー:** テレメトリなし。外部画像は `mdReview.allowRemoteImages` を有効にしない限りブロック。制限モードでは git を実行せず、生 HTML も描画しません。

詳細 (設定、制限事項、開発方法) は [英語版 README](README.md) を参照してください。
